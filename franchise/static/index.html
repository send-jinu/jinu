HOW IT WORKS

자료와 계산 기준

01

원자료

공정거래위원회 가맹사업거래 공시 API의 브랜드·기준연도·지역·가맹점 수·연평균 매출을 그대로 표시합니다.

02

계산값

월평균 매출은 연평균 매출을 12로 나눕니다. 단위면적당 매출은 API 원자료가 없고 평균 면적이 있을 때만 계산합니다.

03

출처

화면과 CSV에 기준연도와 공공데이터포털 출처를 함께 남깁니다. 수익·비용·순이익 추정은 제공하지 않습니다.

공시 매출은 실제 수익이나 미래 매출을 보장하지 않습니다. 투자 판단 전 원문 공시를 확인하세요.
