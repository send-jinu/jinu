# 프랜차이즈 공시 매출 분석

공정거래위원회 가맹사업거래 공시 API를 서버에서 호출해 브랜드별 가맹점 연평균 매출, 12개월로 나눈 월평균 매출, 지역별 가맹점 수·평균 매출, 단위면적당 매출을 보여주는 HTML 앱입니다. 수익·비용·순이익 추정은 포함하지 않습니다.

## 실행

Python 3.11 이상에서 저장소 루트에서 실행합니다.

```bash
export FRANCHISE_SERVICE_KEY='공공데이터포털에서 발급받은 인증키'
python3 franchise/server.py
```

브라우저에서 `http://127.0.0.1:8000`을 열고 브랜드와 기준연도를 입력합니다. 키를 환경변수로 넣지 않은 개발 환경에서는 **인증키 설정** 탭에서 입력할 수 있습니다. 이 방식은 현재 서버 프로세스 메모리에만 유지되며 재시작하면 사라집니다. 키 값은 HTML, JavaScript, 로그, CSV에 들어가지 않습니다.

## API 명세와 해석

기본 operation URL은 공공데이터포털의 공정거래위원회 가맹사업 공시 서비스인 `FftcFranchiseInfoService/getFranchiseInfo`로 설정했습니다. 요청은 `serviceKey`, `pageNo`, `numOfRows`, `type=json`, `brandName`, `year`를 서버에서 전송하며 키는 브라우저로 전달하지 않습니다. 데이터포털 계정에서 발급받은 문서의 operation URL이나 파라미터명이 다른 경우 `FRANCHISE_API_URL` 환경변수로 해당 operation URL을 지정하고, 서버의 정규화 별칭에 맞춰 응답 필드를 연결합니다.

응답은 JSON/XML 모두 읽고, 원자료 행은 `raw`로 보존합니다. 공시 매출 필드는 공정위 문서의 천원 단위를 원으로 환산하며, 월평균은 연평균 ÷ 12로 계산합니다. 단위면적당 매출은 원자료가 없고 평균 매장면적이 같이 반환될 때만 계산하고 출처를 표시합니다. 조회 결과가 없거나 인증·네트워크 오류가 나면 화면에 안내합니다.

## CSV

조회 후 결과 상단의 **CSV 다운로드**를 누르면 원자료와 계산값이 구분된 UTF-8 BOM CSV가 내려옵니다.
